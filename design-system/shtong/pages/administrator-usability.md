# 管理员易用性补充

沿用 MASTER.md 的配色、字体与控件规范。本页针对普通学校工作人员的日常管理。

- 菜单采用「账户管理、身份与权限、学校与班级、操作记录」。界面统一中文，内部契约代码保持稳定。
- 账户按姓名、登录账号、学工号搜索选择；组织显示学校/学院/年级/班级完整名称，不要求填写内部 ID。
- 新建时只展开当前身份需要的班级或管理范围，切换身份清空不适用的选择。
- 提交禁用重复点击，显示处理中；成功后刷新，失败保留输入并显示具体中文原因。弹窗错误显示在弹窗内。
- 导入默认单表，一人一行；模板使用中文表头、中文身份下拉、独立示例及现有组织对照。旧版三表模板继续识别。
- 保留危险操作确认、二次身份验证、另一位管理员复核、审计与后端权限校验。
- ui-ux-pro-max 检索依据：ux 的 Form Labels / Submit Feedback / ARIA Labels；Vue 表单规则；Compose Semantics；SwiftUI Form / accessibilityLabel。简单表单沿用原生校验，复杂状态由复用的请求反馈与选择控件处理。
- frontend-design 实现方向：安静、清晰的学校管理工具，紧凑但不堆叠参数，避免装饰性英文和技术术语。
- 账户分页与全选：每页条数用原生选择框，页码和首末页边界明确；全选用中文命令和勾选图标，跨页加载显示进度并禁重，完成后才改变选择。Vue computed区分草稿筛选与已应用查询，避免旧游标和新筛选混用。依据补充检索的 Loading Buttons / Loading Indicators / Use computed for derived state。
