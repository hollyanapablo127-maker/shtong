# 生化通系统管理员使用手册

适用范围：第一阶段账户、身份权限、学校与班级、操作记录，以及“医保信息系统”统一账号接入。以网页管理端为主；安卓和苹果端采用同样的名称与规则。本文不代表所有客户端均已通过真机验收，验证状态见开发进度文档。

## 一、第一次使用的顺序

1. 使用 Shtong 管理员账号和密码登录；医保模块不再单独登录。
2. 打开“学校与班级”，按学校、学院、年级、班级的顺序建立组织。
3. 人少时使用“新增账户”；人多时下载中文模板，填写后批量导入。
4. 给教师或学生管理员选择管理范围；需要增加身份时进入“身份与权限”。
5. 将初始密码安全地交给本人。普通账户首次登录必须设置自己的密码。
6. 需要删除账户、变更系统管理员或导出操作记录时，由另一位管理员完成安全复核。

不要把管理员密码或包含初始密码的文件发到公共群。离开电脑或手机前请退出登录。

## 二、登录、修改密码和退出

“登录账号”是管理员发放的账号，不一定与姓名或学工号相同。输入账号和密码即可登录，不需要验证码。新密码至少 8 位，并同时包含大写字母、小写字母和数字。

除系统管理员外，首次登录或密码重置后第一次登录，必须输入初始密码和两次新密码。新密码为8至128个字符，不能包含自己的登录账号、学工号等身份信息，也不能是常见弱密码或最近使用过的密码。初始密码不设置有效期，但只能使用一次，完成改密后立即失效。

“个人中心”以列表显示姓名、学号/工号和身份相关信息，不能自行修改姓名。学生显示学校、学院、年级、班级和对应辅导员；辅导员显示管辖年级；其他管理员显示管辖范围。点击“修改密码”进入单独页面。点击“退出登录”后，即使按浏览器返回键或手机返回键，也不能恢复受保护页面。管理员身份验证过期时，重新登录并完成验证后再继续原操作。

## 三、学校与班级

### 建立上下级关系

例如要建立“生化通大学 / 生命学院 / 2026级 / 生物一班”：

1. 添加类型选“学校”，名称填“生化通大学”，填写操作原因，点击“创建学校”。
2. 类型选“学院”，所属学校选择“生化通大学”，名称填“生命学院”，点击“创建学院”。
3. 类型选“年级”，所属学院选择完整路径下的“生命学院”，名称填“2026级”。
4. 类型选“班级”，所属年级选择“生化通大学 / 生命学院 / 2026级”，名称填“生物一班”。

“组织编号”是学校自己使用的短编号，可留空让系统自动生成。有既有学校、学院或班级编号时，可以填入，但不能重复。它不是以前界面中的内部长编号；日常操作不需要知道内部编号。

“上一级”就是所属学校、所属学院或所属年级。以前的“父节点 ID”表示同一关系，现在直接选择名称。不允许学院没有学校、班级没有年级，也不允许选择已停用的上级。

### 修改与删除

通过组织旁的铅笔按钮修改名称，填写原因后保存。组织编号和上下级关系在此界面不做迁移修改，避免误移动已有账户和权限。

“删除”须再次确认。如果该组织仍有下级组织、在用账户或权限引用，系统会拒绝。请先核实关联情况，不要反复点击。删除成功后，原名称和组织编号可再次创建；历史操作记录仍保留。学生转班不在组织页面操作，应到账户详情使用“学籍变动”，不要用删除重建代替。

创建成功后，新组织会出现在列表中；失败时页面显示中文原因并保留输入。看见“正在处理”时不要重复提交。

## 四、新增和查询账户

### 新增一个账户

1. 进入“账户管理”，点击“新增账户”。
2. 填写真实姓名、唯一学工号、唯一登录账号；学生可选填性别。姓名允许重名，请用学工号核对人员。
3. 选择身份。普通用户必须选择所属班级；教师/辅导员、学生管理员需勾选管理范围。
4. 填写操作原因，点击“创建账户”。
5. 保存弹窗中仅显示一次的初始密码，安全交给本人，不要把它当作长期密码。

身份选择规则：

| 身份 | 所属班级 | 管理范围 | 本阶段登录后的界面 |
| --- | --- | --- | --- |
| 普通用户 | 必选 | 不填写 | 空工作台、个人中心、退出 |
| 教师/辅导员 | 可选 | 一个或多个年级 | 空工作台、个人中心、退出 |
| 学生管理员 | 可选 | 学院、年级、班级，可多选 | 空工作台、个人中心、退出 |
| 医保系统管理员 | 可选 | 学院、年级、班级，可多选 | 医保信息系统、个人中心、退出 |
| 系统管理员 | 不从普通新增或模板直接创建 | 系统账户管理，须单独授权及复核 | 四个系统管理模块和医保信息系统 |

### 查询和选择

输入姓名、登录账号或学工号查询，也可按身份、账户状态、组织筛选。点击详情按钮查看所属班级、状态和最近登录。为避免看错人员，请同时核对姓名和学工号。

### 更正资料和办理学籍变动

打开账户详情后，点击“更正资料”可修改登录账号、姓名和学生性别。学工号始终只读，创建后任何端都不能修改；如果学工号录入错误，应停止继续操作并按学校账户治理流程处理，不能用另一个人的编号覆盖。填写明确的更正原因后保存，系统会记录修改前后内容。修改姓名不会自动修改登录账号，姓名也不要求唯一。

学生转班时点击“学籍变动”，从名称路径中选择转入班级并填写原因。系统会保留原班级和新班级的操作记录，并让该学生现有登录失效；学生需重新登录。只有具有普通用户身份的在用学生能办理此操作，教师或仅承担管理工作的账户不会显示该按钮。

列表默认每页20条，可在底部“每页条数”选择10、20、50或100条。“上一页”“下一页”用于翻页，旁边显示当前页和本页人数。第一页没有上一页，末页没有下一页；如果账户数量不足一页，翻页按钮不可用是正常状态，不表示创建失败。修改筛选条件后，先点“查询”再翻页；也可直接点“全选筛选结果”。

勾选表示选中该账户；“选择本页”只选当前页。“全部选择”会跨页选择全部可查询账户；填写筛选条件后按钮变为“全选筛选结果”，点击时会应用当前填写的条件并选择所有匹配账户，不需要先点查询。没有筛选时遵循账户列表的原有规则，已删除账户仍需明确选择“已删除”状态查询，不会偷偷纳入日常批量操作。

全选读取期间会显示进度，读取完毕后才更新勾选数量；中途网络失败不会把部分结果当成全部。“清空选择”取消跨页选择，单独取消一个勾选会保留其余选择。翻页或切换每页条数不会丢失选择；修改筛选条件或重新查询会清空旧选择，避免误操作其他人员。一次最多选择5000人，超出时应缩小筛选条件，不会自动截断到前5000人。批量操作前请核对“已选多少人”。

## 五、批量导入和中文模板

### 下载和填写

1. 先建立组织，再从“账户管理 → 批量导入 → 下载中文模板”下载最新文件。
2. 使用 Excel 或支持该格式的表格软件打开文件。
3. “账户名单”只保留固定表头，从第二行起一人一行。不要把填写说明中的虚构示例当真实账户上传。
4. “组织对照”是下载时有效组织的名称和编号。复制完整名称可避免同名学院或班级混淆。

| 列名 | 怎么填 | 例子或注意事项 |
| --- | --- | --- |
| 登录账号 | 必填且唯一 | student20260001；允许文字、数字、点、下划线和短横线，最长100字 |
| 姓名 | 必填 | 张同学 |
| 学工号 | 必填且唯一 | 00001234，按文本格式保留前导零 |
| 性别 | 学生选填 | 男、女、其他；教师或仅承担管理工作的账户留空 |
| 所属班级 | 普通用户必填 | 学校 / 学院 / 2026级 / 一班，或组织编号 |
| 身份 | 下拉选择 | 普通用户、教师/辅导员、学生管理员 |
| 管理范围 | 教师和学生管理员必填 | 从组织对照复制；多个范围用“；”分隔，普通用户留空 |

每行只填写一个初始身份。一个人需要多个身份时，先导入一次，再通过“身份与权限”增加，不要重复填写同一人。旧版三张英文表和不含性别列的旧中文模板仍能导入，旧名单性别保持未填写；新名单应使用最新中文模板。

### 检查、提交和领取密码

1. 保存为 `.xlsx` 文件，大小不超过10MB，一次最多5000人。
2. 选择文件，点击“检查名单”。此时还没有创建账户。
3. 如有错误，按页面显示的工作表、行号和列名修改原文件。例如“第4行 · 所属班级：找不到有效组织”。保存后重新选择文件并检查。
4. 检查通过后核对人数，点击“确认导入”。页面显示“导入完成”后才算创建成功。
5. 点击“领取初始密码（仅一次）”，妥善保存并分发。文件不是普通账户名单，不要公开。

不要更改表头，不要使用公式、外部链接或隐藏行列。只有名称相同但属于不同学院的班级，必须使用完整路径或组织编号。预检后若组织或已有账户发生变化，系统会要求重新检查，不要绕过提示。

## 六、导出账户

勾选账户时“导出已选”只导出选中的人员；未勾选时导出当前查询条件下的全部账户，包括后续页，不仅当前页。需要真正导出所有在用/非删除账户时，先清空筛选再查询。已删除账户需明确按状态查询。

填写导出用途后再导出。普通账户名单含姓名、账号、学工号、学生性别、身份、状态、班级等，不含密码。导出文件使用中文表头。文件仍包含个人资料，应按学校规定保存和传递。

## 七、重置密码、毕业和删除

### 重置密码

勾选一个或多个账户，点击“重置密码”，填写原因并确认。普通账户重置后旧登录失效，本人下次登录必须改密。涉及系统管理员时需要另一位管理员复核。操作完成后领取并保存一次性的初始密码文件，再安全交给本人。

### 移入毕业生账户

仅对确实毕业的人员执行。勾选人员，点击“移入毕业生”，核对人数并确认。执行后账户不能登录，原有身份会被取消，历史操作记录保留。当前阶段不提供一键恢复到在用账户的功能。

如果人员仍有教师/辅导员、学生管理员或系统管理员身份，系统会拒绝毕业操作。须先核实并按身份变更流程取消相关管理身份，不能直接把管理账户批量毕业。

### 删除账户

删除与毕业不是同一个功能。毕业人员应使用毕业操作，不应为了整理列表直接删除。确认删除后生成安全复核申请；另一位管理员同意后才执行。操作不可从界面恢复，历史审计保留。

## 八、身份与权限

1. 进入“身份与权限”。按姓名、登录账号或学工号查找账户。
2. 选中人员，核对现有身份和管理范围。
3. 在“添加身份”选择所需身份，勾选适用范围，填写原因并确认。
4. 教师/辅导员只出现年级范围；学生管理员出现学院、年级和班级；普通用户与系统管理员不填写此类范围。
5. 系统管理员身份变更进入“安全复核”。出现“等待另一位管理员确认”时尚未生效。

已有同类有效身份不能重复添加。要更换其范围，先核实旧范围并取消旧身份，再添加正确身份；取消与重新添加之间该权限会暂时失效。普通用户身份要求账户已有班级，尚无班级的人员不能直接添加普通用户身份。

取消身份前核对人员、身份及范围，填写原因再确认。身份发生变化后，受影响账户现有登录失效，需要重新登录。不能通过客户端选择绕过服务端权限校验，也不能授权自己受保护的系统管理员身份。

## 九、安全复核

入口为“身份与权限 → 安全复核”。申请列表显示操作类型、原因、涉及人数、发起人和时间。

另一个管理员登录后，核对申请，点击同意或拒绝，填写复核意见并再次确认。发起人和操作所涉及的本人不能替自己复核。系统必须保留至少一位可用系统管理员。

“等待处理”不是“已执行”；“已过期”或“已失效”需要重新发起；数据在等待期间变化也可能导致申请失效。同意后以系统最终状态为准。密码文件和导出文件由发起人返回原功能领取，不在复核页面公开。

## 十、操作记录

选择开始、结束日期和中文操作类型查询，日期范围最多31天。需要按人员查询时，展开“按人员筛选”并搜索选择操作人或涉及人员。点击记录查看结果、人员和详细变化。记录中的内部编号仅供技术人员定位，不需要记忆或抄写才能使用日常功能。

申请导出记录需填写用途，并由另一位管理员复核；确认后回到“操作记录”查看导出结果并下载。操作记录不可由管理员改写或删除。账户查询、导出、登录失败等同样可能产生记录。

## 十一、手机端

安卓与苹果客户端采用中文身份和组织名称选择，不要求输入账户或上级组织内部编号。触摸“账户、权限、组织、记录、我的”进入对应页面。表单失败后保留输入，先处理页面错误，不要重复创建。

导入先下载模板，填写后从系统文件选择器上传；导出和密码文件就绪后还需使用系统“保存文件”完成保存。取消文件保存不等于取消已执行的账户操作。手机空间不足或文件保存失败时，不要把账户创建操作重做一遍。

## 十二、常见问题

| 遇到的情况 | 处理方法 |
| --- | --- |
| 创建按钮不可用 | 检查必填项、是否选择上级、是否正在处理；先创建缺少的上级组织 |
| 提示账号或学工号重复 | 先搜索现有账户，确认不是重复录入，不要随意更改真实学工号 |
| 找不到某班级 | 确认班级已创建、未删除，刷新页面或重新下载模板 |
| 提示多个同名组织 | 使用完整路径或组织编号 |
| 教师不能选学院 | 教师范围按年级设定，可勾选学院下多个年级 |
| 普通用户登录后是空页面 | 未授权模块时只开放个人中心和退出；有有效 `USER` 身份时可从工作台进入医保信息系统 |
| 验证过期或登录失效 | 退出并重新登录；密码、身份变更也会使旧登录失效 |
| 删除或导出一直等待 | 请另一位合格管理员到安全复核处理，不能由发起人自批 |
| 密码文件已经下载过 | 检查本地下载目录；确实丢失时按流程重新重置密码，不能再次读取原密码 |
| 显示成功但列表没刷新 | 先重新查询确认结果，不要立即重复新增 |
| 网络错误，无法判断是否完成 | 查询账户或操作记录核实结果，再决定是否重试 |

无法自行处理时，向维护人员提供功能名称、发生时间、中文提示和必要的记录编号，不要提供密码或整份初始密码文件。
# 毕业生与医保自动审核（2026-09-21）

- 账户管理仅显示正常状态账户；移入毕业生后，到“毕业生管理”按姓名、学工号或学院/年级/班级查询，查看原资料、毕业原因和时间，或导出当前筛选结果。历史档案缺少时间时不推测补录。
- 删除仍沿用原安全复核流程。复核通过后自动同步删除对应医保业务数据与凭证；医保服务暂不可用时后台持续重试，不能把通知失败理解为源账户仍有效。
- 医保新增或修改提交中有缴费凭证时进入后台自动核验；四项匹配则标记“自动审核”，不符合或无法准确识别时仍在原管辖管理员“待审核”中，管理员可随时人工处理。自动核验不替代人工复核权限。
- 参保地只能选择莲池区、保定市内莲池区外、河北省内保定市外、河北省外。只有“保定市”而没有区县的凭证不能自动判定为莲池区外。
